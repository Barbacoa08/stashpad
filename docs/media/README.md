# Preview demonstrations

These demonstrations were captured from the development browser fixture using synthetic notes. The GIFs show sibling reordering and mouse-history navigation; the WebM contains the full preview demonstration. Cursor and caption annotations were added for clarity. Mouse side-button events in the recordings were simulated; physical side buttons were confirmed separately. Browser recordings do not establish native persistence or packaged-app acceptance.

The workspace overview shows the current source UI with synthetic developer notes in a separate in-memory browser fixture. It illustrates Markdown rendering and editable syntax, nested stashes, colors, and the desktop layout. It does not show a personal library, imitate native window controls, or establish native persistence or acceptance. The published DMG may predate the source shown; the root README records that compatibility boundary.
